# n150bench

Interactive CPU benchmark comparison chart highlighting the **Intel Processor N150** against various desktop and laptop processors (Intel Core i3/i5/i7 and AMD Ryzen).

## Features

- **Interactive charts** powered by Chart.js.
- **Metric switching**:
  - PassMark CPU Mark (Multi-Thread)
  - Geekbench 6 (Multi-Core)
  - Geekbench 6 (Single-Core)
- Visual highlighting of the reference processor (Intel N150).

## Usage

Simply open `n150bench.html` in any modern web browser.
